# Images

`index.html` already points at the filenames below. Drop a file in with the matching name and it shows up on the site automatically — no code changes needed.

| Filename | Used for | Suggested size |
|---|---|---|
| `portrait.webp` | Hero portrait (top right) | already added — your Đà Lạt photo, recovered from the old design draft |
| `project-fleet.jpg` | Fleet Logistics Platform card | ~900×480px, landscape |
| `project-agrilens.jpg` | AgriLens card | ~900×480px, landscape |
| `project-robot.jpg` | Robotic Arm Controller card | ~900×480px, landscape |

Notes:
- Any raster format works (`.jpg`, `.png`, `.webp`) as long as the extension in `index.html` matches the file you add.
- Missing files just show a broken-image icon in the browser — fine for now, just fill them in before you actually publish the site.
- Keep individual files under ~500KB so the page loads fast on GitHub Pages.
